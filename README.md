# Crypton Future Media — React + Vite

Complete responsive company website.

## Sections

1. Navbar
2. Home / Hero
3. About
4. Services
5. Why Us
6. Team
7. Contact
8. Footer

## Start

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

All sections are separate React components inside `src/components/`.

Update the placeholder email/social links and team information with your real company details before deployment.
